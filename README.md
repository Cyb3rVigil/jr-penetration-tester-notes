# Junior Penetration Tester Notes

A learning journal for cybersecurity fundamentals, authorized lab practice, and evidence-based technical write-ups.

## Scope and ethics

- Practice only in TryHackMe rooms, intentionally vulnerable labs, CTFs, or systems for which explicit authorization exists.
- Do not publish credentials, personal data, private targets, session cookies, or unapproved vulnerability details.
- Treat these notes as a learning record, not proof of professional assessment experience.

## Suggested structure

```text
.
├── README.md
├── networking/
├── linux/
├── web-security/
├── tools/
├── tryhackme/
├── scripts/
└── reports/
```

Add folders as notes are created. Do not add empty placeholder reports or claim labs are completed before they are completed.

## Lab note template

For each completed lab, record:

1. **Objective** — what the lab teaches.
2. **Environment** — platform/room and date, without private account information.
3. **Method** — high-level steps and tools used.
4. **Evidence** — sanitized screenshots or command output where redistribution is permitted.
5. **Learning** — what worked, what failed, and what you would improve.
6. **Remediation** — the defensive lesson or recommended fix.

## Current status

This repository is a framework for ongoing notes. Add only work that you have personally completed and can explain.

## Responsible disclosure

For any real-world finding, follow the asset owner's published scope and disclosure policy. Never test beyond authorization.
